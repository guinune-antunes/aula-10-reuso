# Comparativo de Bibliotecas HTTP — Python

| Biblioteca | Última atualização | Downloads/semana | Licença | Complexidade da API | Observações |
|-------------|-------------------|------------------|----------|---------------------|--------------|
| requests | out/2024 | ~40 milhões | Apache 2.0 | Baixa | Extremamente popular, fácil de usar, ideal para scripts e automação. |
| httpx | ago/2024 | ~8 milhões | BSD 3-Clause | Média | Suporte a HTTP/1.1 e HTTP/2, assíncrono e compatível com asyncio. |

---

## Decisão Técnica

**Biblioteca escolhida:** `requests`  
**Motivo:** É a biblioteca mais estável e amplamente utilizada para requisições HTTP em Python. Possui uma API muito simples, documentação extensa e excelente compatibilidade.
